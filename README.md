# Adbutam CLI — Universal Cross-Platform Installer (macOS, Linux & Windows)

**Created & Provided by Sai Tej Sunkara (@saitejsunka)**
* **LinkedIn:** https://www.linkedin.com/in/saitejsunka/

---

## 1. Install on macOS (Apple Silicon & Intel) or Linux / WSL2

    curl -fsSL https://github.com/saitejsunka/adbutam-dist/releases/latest/download/install.sh | bash

## 2. Install on Windows (PowerShell)

    irm https://github.com/saitejsunka/adbutam-dist/releases/latest/download/install.ps1 | iex

## 3. Verify Installation

    adbutam --help
