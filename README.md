## 1. Install on macOS (Apple Silicon & Intel) or Linux / WSL2

    curl -fsSL https://raw.githubusercontent.com/saitejsunka/adbutam-dist/main/install.sh | bash

## 2. Install on Windows (PowerShell)

    irm https://raw.githubusercontent.com/saitejsunka/adbutam-dist/main/install.ps1 | iex

## 3. Verify Installation

    adbutam --help
